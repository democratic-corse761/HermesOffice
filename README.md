## 📖 How to Use

### Creating a New Document
1. Open HermesOffice
2. Click "New Document" from the home screen
3. Choose between a blank document or a template
4. Start typing – the AI assistant will appear automatically

### Opening Existing Files
1. Click "Open File" or press Ctrl+O (Cmd+O on Mac)
2. Browse to your DOCX or PPTX file
3. Double-click to open it

### Using the AI Assistant
- The Hermes Agent icon will appear in the toolbar
- Click it to ask for help with writing, formatting, or editing
- Type your request, and the AI will provide suggestions
